# Changelog

All notable changes to this project are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-20

First public release.

### Added

- Interactive gallery with buttons, forms, feedback, controls, a data table, a chart, empty states, and dialogs.
- Tokens, typography, spacing, iconography, and guidelines pages.
- Five palettes and light and dark themes; the theme follows the operating system until the user picks one.
- Reduce motion and reduce transparency settings that respect the operating system preferences.
- Section links with history support and a side navigation that follows the scroll.
- Table with sorting, selection, and bulk delete; keyboard-driven component search.
- Behavior test suite with Vitest and Testing Library.
- CI, GitHub Pages deployment, and contribution guidelines.

### Accessibility

- Control boundaries with at least 3:1 contrast, 24px minimum hit areas, visible focus, and focus management after deletes and navigation.
- WCAG 2.2 AA is a target; the project has not been audited.
